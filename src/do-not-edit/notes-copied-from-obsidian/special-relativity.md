* Two postulates
	* 1. Laws of physics same in all frames of reference
	* 2. Speed of light in vacuum is always 299 792 458 m/s
* (of a property) proper - measured in the reference frame where the object the event happened to is stationary
	* proper time - time for an event to elapse at the place where the event is happening (v=0)
	* proper length - length of an object as measured in the frame where the object is stationary
		* proper distance
	* proper mass - mass of an object as measured when in the frame where the object is stationary (AKA rest mass)
* coordinate - measured in the inertial reference frame of an outside observer
* Time dilation - $t = \gamma t_0$
	* $t$ - time observed by you (time event finished - time event started)
	* $t_0$ proper time - time by the stationary observer where the event happened
* Length contraction - ; in coordinate space, objects appears contracted (shorter) in the direction that they are moving
